## 📖 Sobre o Projeto

Almanaque de Aventuras é um site criado para **centralizar conteúdos recentes de Dungeons & Dragons (D&D) traduzidos** em um único local, facilitando o acesso por mestres e jogadores para uso em campanhas próprias. O projeto tem caráter **pessoal e acadêmico**, sendo usado como laboratório de aprendizado em desenvolvimento web full‑stack.

---

## 🎯 Objetivos

- Reunir e organizar conteúdo traduzido de D&D.
- Facilitar consultas rápidas durante sessões de jogo.
- Servir como projeto de estudo e portfólio técnico.
- Experimentar práticas de desenvolvimento web (front-end, back-end e persistência).

---

## 🛠️ Tecnologias

- **HTML** — Estrutura do front-end
- **JavaScript** — Lógica e interatividade
- **Node.js** — Servidor / back-end
- **MongoDB** — Banco de dados (local ou Atlas)

---

## 🧩 Funcionalidades

- Listagem e exibição de conteúdos traduzidos.
- Organização por categorias/tags.
- Persistência dos itens no MongoDB.
- Interface simples e acessível para consulta durante campanhas.
- Busca avançada e filtros.

## 🚀 Como Executar Localmente

> Ajuste os comandos conforme sua estrutura de pastas e scripts `package.json`.

1. Clone o repositório:
   ```bash
   git clone https://github.com/Caiouuill/Almanaque-de-Aventuras.git
   ```

2. Entre na pasta do projeto:
   ```bash
   cd BackEnd
   ```

3. Instale dependências:
   ```bash
   npm install
   ```

4.  Inicie a aplicação:
   ```bash
   node server.js
   ```

6. Pronto, ele abrira automatico com a porta 3000 por padrao
